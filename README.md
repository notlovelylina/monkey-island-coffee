# Monkey Island Coffee

Welcome to the Monkey Island Coffee project! This website is dedicated to showcasing our coffee shop, its offerings, and providing an online ordering system for our customers.

## Project Structure

```
monkey-island-coffee
├── index.html        # Main landing page with navigation and overview
├── menu.html         # Page displaying menu items (coffee, tea, pastries, breakfast)
├── story.html        # Page detailing the story and mission of Monkey Island Coffee
├── visit.html        # Information on how to visit the coffee shop (location, hours, contact)
├── order.html        # Online ordering page with a selection form
├── css
│   └── style.css     # Styles for the website (layout, colors, fonts)
├── js
│   └── script.js     # JavaScript functionality for interactive elements
└── README.md         # Project documentation
```

## Features

- **Responsive Design**: The website is designed to be mobile-friendly and accessible on various devices.
- **Menu Display**: A dedicated page for showcasing our menu items, including detailed descriptions.
- **Story Section**: Learn about the origins and mission of Monkey Island Coffee.
- **Visit Information**: Easy access to location, hours of operation, and contact details.
- **Online Ordering**: Customers can place orders directly through the website.

## Setup Instructions

1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the website.
3. Ensure that all assets (CSS and JS files) are correctly linked for full functionality.
